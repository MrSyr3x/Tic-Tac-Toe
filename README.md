# ❌⭕ Tic-Tac-Toe — Sketch Edition ✏️

A creative, hand-drawn take on the classic Tic-Tac-Toe — inspired by **Excalidraw’s sketchy aesthetic**!  
Built using **HTML, CSS, and JavaScript**, this project mixes doodle art vibes with fun, fast gameplay 🎨🕹️

---

## 💡 Highlights
- ✏️ **Sketch-Style Interface** — looks hand-drawn and playful  
- 🧩 **Two-Player Gameplay** — play locally with a friend  
- 🏆 **Smart Logic** — detects wins, ties, and invalid moves  
- 🔄 **Reset Option** — replay instantly without reloading  

---

## 🧠 Tech Stack
- HTML — Game grid layout  
- CSS — Hand-drawn look & sketch lines  
- JavaScript — Game mechanics and win detection  

---

## 🚀 How to Play
1. Player X starts first.  
2. Take turns marking the grid.  
3. First to 3 in a row wins 🥇  
4. Hit "Reset" to start over!
